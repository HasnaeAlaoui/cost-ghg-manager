Help

  1. Master Data. Create Materials, WIP, Finished Products, Activities, Equipment and Energy with + New …. Enter material prices and emission liabilities, and equipment and energy reference parameters. Items is the derived registry of MAT, WIP and FP.
  2. Production Information. Create BOM component quantities and Routing activity/equipment/energy assignments with standard execution time and power. Review the Production Graph; WIP can contain further production levels.
  3. Production Order. Select a Finished Product and Order Quantity, then Create Production Order. In Generated ProNodeTree, select the production order and click Generate ProNodeTree. Each repeated use of a produced item retains its own production node identity.
  4. Production Execution. Select a generated Planned order and click Execute Production. ActyResponse.ECSI initializes from standards and ProductionOrder.ECSI becomes Completed. Completed orders remain available for inspection; execution, editing, deletion and regeneration are locked. Use Edit Activity Response to select a production node, edit rEact, powEact, emEact and its direct BOM quantities rMact, including WIP, then Save Activity Response.
  5. Standard Accounting. Use Calculate Standard and Calculate Actual. Review Order Summary and Node Traceability. Order totals include finished-product roots only; recursive node totals overlap and must not be added together.
  6. Variance Analysis. Open the Variance Analysis module, select an executed production order and click Calculate Analytical Variances. Efficiency and price/factor components explain the model's analytical variance; they are distinct from full Actual vs. Standard differences. Real-time Simulation is disabled in v0.1.

Use Save Project to download JSON and Load Project to restore it. Recalculate results after loading or changing inputs. New sessions start empty.

std = standard · act = actual (e.g. PACstd/PACact, PCFstd/PCFact).

Manufacturing Concepts & Resources
MAT / WIP / FP
Purchased material / work in progress / finished product.
Activity / Capacity / Direct resources
Activities use equipment capacity and energy; directly consumed materials contribute direct cost.
BOM / Routing
Bill of materials: components and quantities. Routing: activity, equipment, energy, time and power.
ProductionOrder.ECSI / orderID / orderStatus
Production order / its identifier / Planned before execution, Completed after successful execution.
BOM.ECSI
Canonical product structure. Source parent and child identities resolve through ITEM.TBL to parentItemID and childItemID. bomID identifies the relationship; fpID provides product context, and rMstd and matUOM hold standard design inputs.
Routing.ECSI
Canonical production structure. Source WIP or FP identity resolves through ITEM.TBL to itemID. routeID identifies the relationship; fpID provides product context. Activity, equipment, energy, standard time and power retain their established attributes.
ProNodeTree.ECSI / nodeID
R-generated production occurrences with nodeID, chilNodeID, routeID, bomID, fpID, itemID and itemQuantity. Repeated items retain distinct production nodes; material leaves are display occurrences. Quantities remain per finished-product unit.
Itemization
Generates the read-only ITEM.TBL from finished products, WIP and materials in that order. itemID is assigned using row_number(); source identities are resolved by erpCat plus erpID, never by item names.
matID / wipID / fpID / actyID / eqipID / enyID
Original material / WIP / finished-product / activity / equipment / energy identifiers.
matName / wipName / fpName / actyName / eqipName / enyName
Names in the corresponding source masters.
matDescription / wipDescription / fpDescription / actyDescription / eqipDescription / enyDescription
Descriptions in the corresponding source masters.
actyCat / eqipCat
Activity classification (PrimaryActy or SecondaryActy) / equipment classification (ProductionEQIP or AssemblyEQIP).
parentItemID / childItemID
Generated unified item identifiers of a canonical BOM parent / component.
parentItemName / childItemName
Names derived from the canonical BOM item references.
ActyResponse.ECSI / jobID
Occurrence-specific Activity Response observations / response identifier.
orderStart / orderEnd
Production order start / end date.
bomID / routeID
BOM relationship identifier / routing relationship identifier.
Source Product Structure (BOM CSV)
parCat
Category of the parent entity (FP or WIP).
parID
Identifier of the parent entity in its source master data.
childCat
Category of the component entity (WIP or MAT).
childID
Identifier of the child entity in its source master data.
Source Production Structure (Routing CSV)
wipFpCat
Category of the produced entity (WIP or FP).
wipFpID
Identifier of the produced entity in its source master data.
Generated ITEM.TBL
itemID
Unified item identifier generated during itemization.
erpID
Identifier of the entity in its originating master data.
erpCat
Source entity category (final, semi, or mat). Source FP, WIP and MAT map to final, semi and mat, respectively.
itemName
Name of the item.
itemCat
Item classification (finished, intermediate, or material). Finished products, WIP and materials map to these classifications, respectively.
Generated ProNodeTree.ECSI
itemQuantity
Quantity of the item required at this production node to fulfill one finished-product unit. Propagated recursively as curQty * rMstd.
chilNodeID / rootNodeID
Child production-node identifiers / finished-product root identifiers used for order totals.
orderQuantity
Number of finished-product units requested in a production order.
Production Parameters

Time inputs use minutes; energy/GHG calculations convert minutes to hours.

rEstd / rEact
Routing rEstd and Activity Response rEact are recorded in min/unit. Variance tables show rEstd per unit and rEact in minutes (observation × itemQuantity).
rMstd / rMact
Direct BOM consumption, including WIP · quantity per parent unit.
powEstd / powEact
Power · kW; energy consumed = (rE / 60) × powE.
emEstd / emEact
Energy emission coefficient · kgCO₂e/kWh; actual coefficient belongs to the production node.
ECact
Actual energy consumed at the production node · kWh; (accounting rEact / 60) × powEact.
pEstd / qEstd
Full / variable equipment cost rate · EUR/min.
qMstd
Material price · EUR per material unit.
uMELstd
Material emission liability · kgCO₂e per material unit.
uEELstd
Equipment emission liability · kgCO₂e/eqip.
matUOM / eqipUOM / powUOM
BOM consumption unit / routing execution-time unit / power unit.
uOMqM / uOMuMEL / uOMpE / uOMqE / uOMuEEL / uOMemE
Units of material price / material emission liability / full cost rate / variable cost rate / equipment emission liability / energy emission coefficient.
costUOM / ghgUOM
Accounting result units: EUR / kgCO2e.
ltCapacity
Equipment lifetime capacity.
cuEELstd
Capacity-unit equipment emission liability · cuEELstd = uEELstd / ltCapacity.
Cost Accounting Metrics

EUR · Recursive results; order totals use finished-product roots only.

PAC
Production Activity Cost.
PACv / PACf
Variable / fixed activity cost · PACf = PAC − PACv.
PDC
Production Direct Cost: purchased-material costs and recursively included WIP direct costs.
PC
Production Cost · PC = PAC + PDC.
PCstdUnit / PCactUnit
Standard / actual order production cost divided by orderQuantity.
PCv / PCf
Variable / fixed production cost · PCv = PACv + PDC; PCf = PACf.
GHG Accounting Metrics

kgCO₂e · Scope descriptions follow the methodology’s classification.

PACF
Production Activity Carbon Footprint · local contribution = (rE / 60) × powE × emE, using the corresponding standard or actual inputs.
PECF
Production Equipment Carbon Footprint · local contribution = (rE / 60) × cuEEL, using the corresponding standard or actual inputs.
PMCF
Production Material Carbon Footprint: purchased-material emissions and recursively included WIP material emissions.
PCFint
Internal Production Carbon Footprint · PCFint = PACF.
PCFext
External Production Carbon Footprint · PCFext = PECF + PMCF.
PCF
Production Carbon Footprint · PCF = PCFint + PCFext.
PCFstdUnit / PCFactUnit
Standard / actual order carbon footprint divided by orderQuantity.
Scope 1
Internal activity emissions from combusted energy sources.
Scope 2
Internal activity emissions from purchased electricity.
Scope 3
Embedded upstream equipment/material emissions represented by the methodology.
Analytical Variances

Cost variances: EUR · GHG variances: kgCO₂e.

PACEV / PACPV
Variable activity-cost efficiency / price-rate variance.
PDCEV / PDCPV
Direct-material cost efficiency / price variance; efficiency includes WIP-consumption effects.
PACFBV / PDCFBV
Variable activity / direct-material flexible-budget variance: each sums its efficiency and price components.
PCEV / PCPV
Production cost efficiency / price variance · PCEV = PACEV + PDCEV; PCPV = PACPV + PDCPV.
PCFBV
Production Cost Flexible-Budget Variance · PCFBV = PCEV + PCPV; distinct from PCact − PCstd.
PACFEmV / PACFEnyV
Activity GHG emission-coefficient / energy-consumption variance.
PECFEV / PECFELV
Equipment GHG input / emission-liability variance.
PMCFEV / PMCFELV
Material GHG input / emission-liability variance.
PACFTV / PECFTV / PMCFTV
Total activity / equipment / material GHG variance: each sums its two components.
PCFintTV / PCFextTV
Internal / external GHG variance · PCFintTV = PACFTV; PCFextTV = PECFTV + PMCFTV.
PCFTV
Total production GHG variance · PCFTV = PCFintTV + PCFextTV.
Direct local deviation
Actual vs. Standard for own activity, equipment emissions and purchased-material contributions; excludes child WIP.
Recursive deviation
Actual vs. Standard for recursive results, including descendants and parent WIP-quantity effects.
Analytical variance
Efficiency and price/factor components; zero direct local deviation does not exclude WIP-related drivers.

Source: Baumüller, J. & Schwaiger, W. S. A. (2026). Activity-Based Standard-Cost & GHG-Accounting Methodology: Integrating economic cost and ecological GHG emission into a common diagnostic management control system. European Accounting Association (EAA) 2026, Prague, Version 2.0.
